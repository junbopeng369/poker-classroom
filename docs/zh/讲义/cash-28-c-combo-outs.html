4. 命中同花也可能仍输

转牌 A♥K♥2♣3♦；你拿 8♥7♥，已知对手 Q♥J♥。

这里双方手中都有两张红桃，对手的两张点数都更高。河牌再来红桃时，双方都能组成同花，而对方的同花更大。不能把这些红桃当成你的干净获胜补牌。
