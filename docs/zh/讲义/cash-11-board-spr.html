1. 先看牌面帮到了谁

A 高干燥牌面与相连的中低牌面，连接的范围不同。

翻前加注者常有较多强 A 和大对子，跟注者可能有更多相连中低牌。但实际范围取决于位置和动作；不能只凭“我是加注者”决定所有翻牌都下注。

3. SPR 是剩余筹码除以底池

底池 60，双方剩余有效筹码 240，SPR = 4。

SPR 描述后续可以投入多深。相同底池下剩余 600，SPR 就是 10。它是计划工具，不能单凭一个数字决定顶对必须打光或必须控池。

4. SPR 很低就必须全下吗？

SPR = 2，你拿中等一对，对手在不利牌面大额加注。

小 SPR 限制了行动空间，但对手范围和你的相对牌力仍然重要。已经有不少筹码在底池里，不等于剩余筹码必须投入。

SPR = 2，你拿中等一对，对手在不利牌面大额加注。

练习：

  1. 不是，还要比较范围、牌力和价格
  2. 是，SPR 小于 3 就必须打光
参考与各选项解释
  • 参考选择「不是，还要比较范围、牌力和价格」：正确。SPR 帮助规划，不代替决策。
  • 其他选项「是，SPR 小于 3 就必须打光」：不存在脱离范围和牌面的通用阈值。

5. 每条街重新看三件事

牌面怎样变、双方范围怎样变、还剩多少筹码。
