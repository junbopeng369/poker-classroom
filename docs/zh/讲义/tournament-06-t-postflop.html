2. 你的牌要与对手范围比较

你拿 T♠T♦，翻牌 J♣9♥4♠。

这是中等摊牌价值的一对。它可能领先一些小对子、听牌或空气，也落后 Jx 和更强牌。低 SPR 本身不会把它变成必须全下的价值牌。

3. 小注与大注留下不同空间

从 26,000 中下注 4,000 或 13,000，后续筹码截然不同。

选择尺度需要目的：哪些较差牌支付，哪些较好牌会弃，或者能否让对手放弃其胜率。还要预想面对全下时自己的范围与价格。

4. 什么计划更合理？

你在低 SPR 局面考虑下注，但尚未想过被全下怎么办。

选择能帮助当前决策的做法。计划不是不论什么新信息都执行，而是先知道哪些信息会改变行动。

你在低 SPR 局面考虑下注，但尚未想过被全下怎么办。

练习：

  1. 先比较对手反应与自己愿意继续的条件
  2. 先下注，已经投进去再说
参考与各选项解释
  • 参考选择「先比较对手反应与自己愿意继续的条件」：正确，尺度和后续计划一起考虑。
  • 其他选项「先下注，已经投进去再说」：这容易让旧投入替代当前判断。
