# Poker Study Room · 扑克训练室

Bilingual static lessons for live cash games and tournaments.

Website: https://junbopeng369.github.io/poker-classroom/

- 57 narrated lessons per language: 36 cash-game and 21 tournament lessons.
- 20 decision trees with 191 nodes and 35 situation entry points.
- 25 conditional range charts, calculators and 60 practice drills.

GitHub Pages publishes the `docs/` folder on the default branch. All links work under the project-site path. Audio is delivered as MP3; captions use the existing alignment. No account or backend is needed, and progress stays in the visitor’s local browser.

These are original, conditional teaching examples, not solver-certified strategies. Narration is AI-generated.
